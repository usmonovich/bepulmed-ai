# BepulMed AI 2.11 — исправления по скриншотам

- «Маршрут» больше не открывает браузер (Chrome): всегда своя навигация внутри приложения.
  Если точка учреждения ещё не известна — центр района, крупно адрес, кнопки «Позвонить» и
  «Найти адрес в навигаторе» (Android: geo: — Яндекс/2GIS/Google Карты, не браузер).
- Карта без интернета и без данных: вместо «Не удалось загрузить учреждения» — гос. учреждения
  вашего района и экстренные центры из справочника приложения (адрес, телефон, маршрут).
- Карта справочника без координат: районы Ташкента с числом учреждений, нажатие → список района.
- Пояснение на карте, если в сборке нет встроенной карты Ташкента.

Проверено: e2e в точности ваш сценарий (Android, первый запуск, интернета нет, карта не встроена):
ни одного перехода в браузер, ошибок нет; кнопка навигатора даёт geo:-ссылку. web 128 тестов.

Важно: APK из чата по-прежнему без встроенной карты и снимка аптек — их нельзя скачать из этой среды.
