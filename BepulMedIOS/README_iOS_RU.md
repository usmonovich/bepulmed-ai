# BepulMed AI 2.7 для iPhone (iOS 15+)

Тот же интерфейс и те же офлайн-функции, что в Android-версии: интерфейс, OCR-модели, база клиник Ташкента,
первая помощь и бесплатные лекарства лежат внутри приложения. Нативная часть на Swift (без сторонних библиотек):

| Файл | Что делает |
|---|---|
| `AssetSchemeHandler.swift` | раздаёт интерфейс из `www/` по адресу `bepulmed://app/` — без интернета |
| `NativeBridge.swift` | мост `window.BepulMedNative` (тот же, что в Android): распознавание речи `SFSpeechRecognizer` (по умолчанию только на устройстве; через Apple — только с согласия), озвучка `AVSpeechSynthesizer`, геокодер `CLGeocoder`, геолокация `CoreLocation` |
| `TileSchemeHandler.swift` | офлайн-кэш карты `bmtile://` — просмотренные фрагменты OSM, до 120 МБ |
| `bridge.js` | подключает мост к странице (WKWebView умеет только асинхронные сообщения) |
| `WebViewController.swift` | экран, ссылки `tel:`/карты/Telegram — в системные приложения |

## Вариант 1. Есть Mac с Xcode 15+
```sh
cd BepulMedIOS
./prepare_www.sh            # соберёт веб-интерфейс в BepulMed/www (нужен Node.js 20+)
open BepulMed.xcodeproj
```
В Xcode: **Signing & Capabilities → Team** — выберите свой Apple ID (бесплатный подходит), подключите iPhone → ▶ Run.
С бесплатным Apple ID приложение работает 7 дней, потом нужно заново нажать Run.
Если проект не открывается: `brew install xcodegen && xcodegen generate` — пересоздаст его из `project.yml`.

## Вариант 2. Mac нет — сборка в GitHub
1. Загрузите весь проект в репозиторий GitHub (папки `bepulmed`, `BepulMedIOS`, `.github`).
2. **Actions → iOS build → Run workflow**. Через ~10 минут в **Artifacts** появится `BepulMed-AI-2.7-unsigned.ipa`.
3. Установка на iPhone: **Sideloadly** или **AltStore** (Windows/Mac) подпишут .ipa вашим Apple ID.
4. Для TestFlight/App Store нужен Apple Developer Program ($99/год) и подпись сертификатом.

## Вариант 3. Сразу, без установки
На iPhone веб-версия уже работает как **Telegram Mini App** (или в Safari → «На экран Домой»).
Голосового ввода там нет (речь не отправляется на внешние серверы по политике 2.6), остальное — так же.

## Особенности iOS
- **Офлайн-распознавание речи**: Настройки → Основные → Клавиатура → «Диктовка» → язык «Русский».
  Узбекского распознавания у Apple, вероятно, нет — тогда используется русское (как и озвучка).
- Геолокация, микрофон, камера — системные запросы при первом использовании (тексты в `Info.plist`).
- Сервер для записи к врачу указывается в меню → ⚙️ Сервер (как в Android). Запись выключена,
  пока не утверждён хостинг для данных пациентов (политика 2.6).
