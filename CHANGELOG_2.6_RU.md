# BepulMed AI 2.6 — изменения относительно 2.5

## Сохранено из 2.5
- 31 офлайн-инструкция первой помощи RU/UZ, поиск по описанию, СЛР-метроном, вызов 103/112.
- Главный экран и голосовой роутер по разделам.
- 104 учреждения Ташкента, фильтр районов, поиск, координаты/маршруты.
- Каталог лекарств, OCR рецептов/анализов локально на устройстве.
- SOS и локальная медкарта.
- Запись, очередь, талоны и кабинет клиники как исходный функционал (но production API закрыт по умолчанию).

## Изменения 2.6
- Медицинский чат выполняется локально на устройстве; история симптомов не отправляется в Worker. Серверный маршрут чата закрыт по умолчанию.
- Медицинский чат не отправляет историю сообщений в Gemini/VoiceLab.
- Внешние STT/TTS запросы отключены по умолчанию; Android распознаёт речь только on-device, Web Speech API отключён, если нет локального движка.
- API записи, очереди и кабинета клиники закрыт, пока оператор явно не подтвердит проверенный хостинг пациентских данных.
- Планировщик очереди не выполняется без такого подтверждения.
- Android WebView проверяет точный HTTPS origin локального интерфейса; сохранена логика офлайн-распознавания речи 2.5.
- Справочник клиник явно помечен как справочный, а не государственный реестр.
- Добавлены документы по ЗРУ-547/ЗРУ-1125, DMED и условиям production.

## Что НЕ заявляется как завершённое
- Нет развёрнутого backend/БД на подтверждённой площадке в Узбекистане.
- Нет официального DMED API-подключения, OAuth/sandbox или проверки ПИНФЛ.
- Нет юридического заключения/регистрации базы.
- Нет полного клинического утверждения всех памяток.
- Нет собранного и проверенного APK 2.6.
