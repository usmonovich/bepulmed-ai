# BepulMed AI 2.10 — офлайн-карта, навигация, автообновление

Цель: приложение работает примерно на 90% без интернета, а при подключении само обновляет данные.

## Встроенная карта Ташкента
- Векторная карта (улицы, подписи, вода, здания) внутри APK/iOS — открывается без интернета.
  Формат PMTiles, данные © OpenStreetMap (ODbL), схема Protomaps; рисуется на телефоне (protomaps-leaflet).
- Карта встраивается при сборке: `bepulmed/web/scripts/fetch_tashkent_map.sh` вырезает Ташкент
  (69.05–69.52 в.д., 41.13–41.47 с.ш., до масштаба 15) из открытой ежедневной сборки Protomaps.
  Скрипт запускается в GitHub Actions (`.github/workflows/android.yml`, `ios.yml`) — там есть интернет.
- Android: файл хранится в APK без сжатия и читается кусками (HTTP Range → 206) — без загрузки в память.
  iOS: то же через FileHandle. За пределами Ташкента — онлайн-подложка с кэшем просмотренного.

## Аптеки и клиники с первого запуска без интернета
- Снимок OSM (аптеки, поликлиники, больницы: часы, телефоны, адреса) встраивается при сборке:
  `scripts/prefetch_offline_data.ts` → `public/data/tashkent_osm.json`.
- Координаты 104 гос. учреждений считаются из снимка на телефоне — без сети.

## Навигация без интернета
- Кнопка «Маршрут» → экран навигации: моё положение по GPS (работает без интернета), учреждение,
  линия, расстояние и направление («95 м на северо-восток»), время пешком, обновление на ходу, «Вы на месте».
- «Маршрут по улицам в навигаторе» — Android: любой установленный навигатор (geo:), iOS: Apple Карты.

## Автообновление
- При запуске, при появлении интернета и при возвращении в приложение: обновляются аптеки и клиники
  (если данным больше 3 дней) и недостающие координаты. Не чаще раза в 30 минут; без сети — ничего не делает.
- Уведомление «🔄 Данные обновлены»; время последнего обновления — на экране «Офлайн-готовность».
- Удалён старый автозапуск загрузки, который пытался ходить в сеть без интернета.

## Проверено
- web 128 тестов (снимок, автообновление, навигация), worker 153, tsc.
- e2e полностью без интернета на ТЕСТОВОМ пакете карты (искусственные улицы, собран здесь, в приложение

## Ограничения
- Настоящая карта Ташкента здесь не встроена: отсюда нет доступа к Protomaps/OSM. Её встроит GitHub Actions
  (или запуск скрипта на компьютере с интернетом). APK из этого чата — без карты (подложка по сети + кэш).
- Скрипт карты не запускался (нет сети); адрес сборок Protomaps можно переопределить PMTILES_SOURCE.
- Пошаговый маршрут по улицам без интернета — во внешних навигаторах с офлайн-картами; внутри — направление по прямой.
- Обновление самой карты — с обновлением приложения (данные аптек/клиник обновляются сами).
- Веб-версия (Telegram Mini App) — без встроенной карты (лимит 25 МБ на файл в Cloudflare).
