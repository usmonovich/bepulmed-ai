# BepulMed AI 2.7 — «офлайн-первый» на базе 2.6 compliance-hardened

## Что взято из 2.6 и сохранено
- Флаги защиты данных по умолчанию выключены: пациентские данные не пишутся в Cloudflare D1, текст симптомов и голос не уходят во внешний ИИ без явного разрешения.
- Чат и голосовой помощник работают только на устройстве.

## Исправлено в 2.6
- Веб-часть 2.6 не собиралась (литеральный `\n` в `lib/api.ts`).
- 31 тест сервера падал (запись закрыта по умолчанию) — тесты интеграции получают явное разрешение, добавлены тесты «по умолчанию данные защищены».
- Возможный вылет на Android 12: `isOnDeviceRecognitionAvailable` вызывался на API 31 (метод есть только с API 33).
- Голос был отключён у большинства пользователей (нет офлайн-пакета узбекского/русского): теперь помощник предлагает скачать офлайн-пакет или явно разрешить Google-распознавание (согласие хранится на телефоне, можно отозвать).

## Из 3.0
- Поиск учреждений OSM по тегам `healthcare=*` (больше поликлиник и центров).
- Дополнительные пункты «нельзя» в первой помощи (СЛР на твёрдой поверхности, не бить по спине при сильном кашле, не промывать глубокую кровоточащую рану и др.).

## Новое: максимально офлайн
- **Кэш карты в APK**: просмотренные тайлы OpenStreetMap сохраняются на телефоне (до 120 МБ) и показываются без сети. Массовой предзагрузки нет — это запрещено правилами OSM.
- **Талоны без сети**: последний список талонов сохраняется; без связи показываются талон и QR-код (QR строится на телефоне), с пометкой «сохранено офлайн»; отмена и очередь скрыты.
- **Экран «Офлайн-готовность»** (меню → 📴): что работает без интернета, координаты N/104, OSM-кэш, тайлы, OCR-модели, голос, озвучка, медкарта, талоны; кнопка «Подготовить к работе без интернета».
- **Индикатор «📴 Офлайн»** в шапке.
- **Service worker для веб-версии** (Telegram Mini App/браузер): оболочка и OCR-модели открываются без сети после первого запуска. В APK не используется.
- Голос: «что работает без интернета» → экран офлайн-готовности.

## Первая помощь: точнее и безопаснее (34 инструкции)
- Новые: «Ушиб, ссадина, небольшой порез», «Укус клеща, пчелы, осы» (с предупреждением о крымской геморрагической лихорадке).
- Исправлены опасные подмены поиска: «сильное кровотечение из ноги» → было «кровь из носа»; «ушиб» → было «гипогликемия» (совпадение с узб. «tushib»); «что делать при ожоге» уходило в чат.
- Слабое совпадение больше не открывает инструкцию само: помощник говорит «Похоже на …» и показывает кнопку.

## Проверено
- web: 90 тестов, worker: 126 тестов, tsc без ошибок.
- APK 2.7 собран и подписан (versionCode 27).
- Сквозной тест в Chrome при полностью отключённом интернете (имитация Android-моста): индикатор офлайн, согласие на распознавание → распознавание, подсказка «похоже на ожог» → инструкция, голосовой переход на «Офлайн-готовность», OCR 5/5 файлов, талон и QR из сохранённой копии, новые разделы первой помощи. Ошибок страницы нет.

## Ограничения
- Офлайн-помощник — база знаний и разбор намерений на устройстве, не нейросеть.
- Координаты клиник и OSM-кэш нужно один раз загрузить при наличии интернета.
- На реальном телефоне APK 2.7 не запускался; кэш тайлов и голосовые функции проверены только через имитацию моста.
- Запись к врачу выключена, пока не утверждён хостинг для пациентских данных (политика 2.6).
