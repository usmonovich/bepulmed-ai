# BepulMed AI — Android-приложение (APK)

**Готовый APK:** `BepulMed-AI-2.6.apk` (≈12 МБ, Android 8.0+; большая часть — модели распознавания текста RU/UZ/EN, встроенные для работы без интернета). Установка: скопировать на телефон → открыть → разрешить «Установку из неизвестных источников».

## Как устроено

- **Интерфейс внутри APK** (`app/src/main/assets/www` — сборка `bepulmed/web`). WebView получает его по адресу
  `https://appassets.androidplatform.net/` (домен, зарезервированный Android для локального контента).
  Приложение открывается мгновенно, а **SOS, медкарта и сканер документов работают без интернета и без сервера**.
- **Сканер (v2.3):** движок Tesseract и языковые модели (русский, узбекский, английский) лежат внутри APK — ничего не скачивается.
- **Ташкент без сервера (v2.3):** при первом запуске с интернетом приложение само скачивает из OpenStreetMap все больницы,
  поликлиники и аптеки Ташкента и хранит их на телефоне (обновление раз в 30 дней или кнопкой «Обновить» на карте).
  Список «Рядом» работает без сервера и без интернета; подложка карты без интернета не загружается.
- **v2.6: главный экран** — большая кнопка в центре сразу запускает помощника. **Раздел «Скорая»** — 31 офлайн-инструкция первой помощи
  (RU/UZ, по IFRC 2020 и ERC), поиск по описанию ситуации, метроном для реанимации, чтение вслух, экстренные номера 103/112/101/102/104/1050.
  **Помощник управляет всеми функциями**: первая помощь, «вызови скорую», «ближайшая поликлиника» (GPS), лекарства, медкарта, SOS, сканер, запись, язык.
  **Координаты клиник**: при первом запуске с интернетом — сопоставление с OpenStreetMap + системный геокодер Android, с проверкой
  (в Ташкенте, ≤7 км от района, без точек-«заглушек»); дальше карта точек и расстояния работают офлайн. Распознавание речи без
  интернета — на устройстве (Android 13+, если установлен офлайн-пакет языка).
- **Голосовой помощник (v2.4):** кнопка 🎙️ вверху. Распознавание и озвучка — системные Android (SpeechRecognizer, TextToSpeech)
  через мост `window.BepulMedNative`, язык ru-RU / uz-UZ. Команды: «бесплатные лекарства от давления» → вкладка лекарств,
  «поликлиника в Чиланзаре» → справочник, «боль в груди» → 103/SOS, вопросы → ответ голосом. Узбекского голоса синтеза нет
  на многих телефонах — тогда ответ читается русским голосом (текст на экране — по-узбекски).
- **Справочник клиник Ташкента (v2.4):** 104 государственных учреждения встроены в приложение (26 республиканских центров с
  телефонами — gov.uz; ~78 семейных и районных поликлиник по 12 районам — goldenpages.uz/yellowpages.uz), поиск, фильтр района, «мой район» по GPS, маршрут по адресу.
- **Бесплатные лекарства (v2.4):** все 69 препаратов приказа МЗ № 18 от 23.04.2026, поиск по названию, торговой марке, симптому (RU/UZ, с опечатками).
- **Чат без сервера (v2.3):** экстренные признаки → 103/112, остальные вопросы — ответ из встроенной базы официальных источников.
- **Запись, очередь, талоны, чат и карта** работают через сервер BepulMed (Cloudflare Worker). При первом запуске приложение
  попросит адрес сервера (`bepulmed-ai.<имя>.workers.dev`) и проверит его через `/api/health`. Сменить: ☰ → «Сервер».
- **Нативная часть** (`MainActivity.java`, `CameraProvider.java`) — чистый Java без внешних библиотек:
  - разрешения Android на камеру (сканер, QR в кабинете), микрофон (голос), геолокацию (карта, SOS);
  - съёмка документа камерой или выбор из галереи; снимки хранятся в кэше не дольше суток;
  - 103/112 → набор номера; SMS близкому; **SOS → системное «Поделиться»** (WhatsApp, Telegram, SMS…);
  - маршруты и внешние ссылки — во внешних приложениях; защита от выхода за пределы `assets/www`.

## Сборка

**Вариант 1 — без Android Studio** (так собран приложенный APK), Ubuntu/Debian:
```bash
sudo apt-get install aapt apksigner zipalign dalvik-exchange openjdk-17-jdk-headless
cd bepulmed/web && npm ci && npm run build      # интерфейс
cd ../../BepulMedAndroid && ./build.sh ../bepulmed/web/dist
# → build/BepulMed-AI-2.6.apk
```
`android.jar` (API 34) скрипт скачает сам. Подпись — ключом `bepulmed-release.jks` (пароль `bepulmed`).
**Это демо-ключ.** Для Google Play создайте свой: `KEYSTORE=my.jks KS_PASS=… ./build.sh`. Храните ключ: обновления подписываются им же.

**Вариант 2 — Android Studio:** File → Open → эта папка → Build → Build APK(s).
Интерфейс уже лежит в `assets/www`. После изменений в `bepulmed/web` выполните `npm run build` и `./build.sh` (или скопируйте `web/dist` в `app/src/main/assets/www`).

## Что проверено

- APK собран и подписан (v2 + v3), `apksigner verify` проходит. Пакет `uz.bepulmed.app`, minSdk 26, targetSdk 34.
- Java-код скомпилирован против Android API 34, логика выдачи файлов проверена на JVM (11/11, включая защиту от `..`).
- Интерфейс в «режиме APK» (тот же адрес, User-Agent и раздача файлов) пройден в Chrome: первый запуск → подключение сервера →
  запись к врачу через внешний сервер (CORS) → талон с QR; медкарта, SOS с координатами, работа без сервера.
- **На реальном телефоне/эмуляторе не запускался** (в среде сборки нет Android). Проверьте: камера в сканере, «Поделиться» в SOS,
  разрешение геолокации. Отладка: Chrome → `chrome://inspect` (APK собран с флагом отладки WebView).

## Ограничения

- Вход в APK — демо-идентификатор устройства (в Telegram — подпись Telegram). На сервере нужно `REQUIRE_TELEGRAM = "false"`.
  Для реального запуска нужен вход по SMS-коду.
- Уведомления о листе ожидания — только в Telegram; в APK предложение видно во вкладке «Талоны» (push/FCM не подключены).
- Обновления интерфейса приходят вместе с новым APK (интерфейс внутри приложения).
- Локальный сервер с эмулятора (`http://10.0.2.2:8787`) возможен, но надёжнее тестировать с развёрнутым `workers.dev`.
