# Врачи и часы приёма поликлиник (2.12)

## Что видит пациент
Клиники → поликлиника → «Врачи и часы приёма, отзывы»:
адрес, телефоны, режим работы (OpenStreetMap), навигация, врачи по специальностям
(семейный врач, педиатр, гинеколог, невролог, кардиолог…), часы приёма по дням, «принимает сейчас до 13:00»,
кабинет, отметка «по направлению семейного врача» для узких специалистов, рейтинг 2GIS.
Без интернета — последнее сохранённое расписание с датой. Поиск «невролог» в справочнике.

## Откуда расписание
1. **Регистратура публикует в BepulMed** — `https://<сервер>/#/admin/doctors` (ключ сотрудника,
   роль «регистратор» или «администратор»). Сохраняется ФИО, специальность, кабинет, часы по дням;
   каждое сохранение — в журнал. Работает и при выключенной записи: данных пациентов здесь нет.
2. **DMED** — PractitionerRole (FHIR) после регистрации приложения и входа пациента.

## Подключить поликлинику
```sql
-- id из web/src/data/tashkentFacilities.ts (например, f40 — Семейная поликлиника №35)
INSERT INTO clinics (id, name_ru, name_uz, kind, lat, lon, connected, facility_ref)
VALUES ('sp35', 'Семейная поликлиника №35', '35-sonli oilaviy poliklinika', 'clinic', 41.285, 69.21, 1, 'f40');
-- ключ сотрудника: храните только SHA-256
INSERT INTO clinic_staff (id, clinic_id, name, role, token_hash) VALUES ('reg35', 'sp35', 'Регистратура', 'registrar', '<sha256 ключа>');
```
Миграция: `migrations/0004_directory.sql` (`npx wrangler d1 migrations apply bepulmed`).

## API
- `GET /api/directory/doctors?facility=f40` — открыто, кэш 15 мин.
- `GET|PUT /api/staff/directory` — регистратура (Bearer-ключ).

## Чего нет
Открытого источника расписаний врачей государственных поликлиник нет: данные есть у самих поликлиник и в DMED.
Пока поликлиника не опубликовала расписание — страница говорит об этом и даёт телефон регистратуры.
